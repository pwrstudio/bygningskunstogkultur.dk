# Studio

Sanity studio for Magasin for Bygningskunst og Kultur, deployed at
https://mbk-admin.sanity.studio. See the [repository README](../../README.md)
for setup, environments and how the site consumes the content.

| Where                            | What                                                                |
| -------------------------------- | ------------------------------------------------------------------- |
| `schemaTypes/`                   | Document and object types (`defineType`); `index.ts` registers them |
| `deskStructure.ts`               | The left-hand menu; "Om IBK" and "Kolofon" are singletons           |
| `actions/`                       | The "Preview" document action (opens the preview site)              |
| `components/`                    | Editor previews for audio, video and embed blocks                   |
| `sanity.types.ts`, `schema.json` | Generated by `pnpm typegen` — do not edit by hand                   |

```bash
pnpm dev       # http://localhost:3333
pnpm lint      # ESLint
pnpm typegen   # regenerate schema.json and sanity.types.ts after schema changes
pnpm deploy    # publish the studio (sanity login first)
```
